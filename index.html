Lecture du flux OBS

Cette app lit un flux HLS .m3u8. OBS doit envoyer son signal vers un serveur RTMP/HLS comme Owncast, Nginx RTMP, Mux, Cloudflare Stream ou LiveKit.

Constructeur d’URL HLS

Cet outil génère automatiquement les informations nécessaires pour connecter OBS à ton système de diffusion Meyden.

Réglages OBS

1. OBS → Settings → Stream.
2. Service : Custom.
3. Server : ton URL RTMP. Exemple : rtmp://ton-domaine.com/live
4. Stream Key : la clé définie dans ton serveur.
5. Ton serveur transforme le signal en HLS .m3u8 pour cette app.
